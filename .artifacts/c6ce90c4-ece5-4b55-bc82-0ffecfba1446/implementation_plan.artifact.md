# Fix Hilt Plugin Not Found Error

The project is failing to sync because the Hilt and KSP plugins are applied in `app/build.gradle.kts` but their versions and sources are not defined in the project-level configuration or version catalog.

## Proposed Changes

### Build Configuration

#### [MODIFY] [libs.versions.toml](file:///C:/Users/SANTIAGO MUÑOZ/AndroidStudioProjects/My_Car/gradle/libs.versions.toml)
- Add versions for Hilt and KSP.
- Add plugin definitions for `com.google.dagger.hilt.android` and `com.google.devtools.ksp`.
- Add library definitions for Hilt to replace hardcoded strings.

#### [MODIFY] [build.gradle.kts (root)](file:///C:/Users/SANTIAGO MUÑOZ/AndroidStudioProjects/My_Car/build.gradle.kts)
- Declare Hilt and KSP plugins in the `plugins` block with `apply false`.

#### [MODIFY] [build.gradle.kts (app)](file:///C:/Users/SANTIAGO MUÑOZ/AndroidStudioProjects/My_Car/app/build.gradle.kts)
- Update the `plugins` block to use `alias(libs.plugins.dagger.hilt.android)` and `alias(libs.plugins.ksp)`.
- Update the `dependencies` block to use library aliases from `libs.versions.toml`.
